### C. Design patterns worth copying (our synthesis)
1. **Exact-string Edit + mandatory Read-before-Write** — eliminates most destructive-file bugs; verify-first contract.
2. **System-reminder injection** — dynamic context (todos state, CLAUDE.md reminders, hook feedback) rides in `<system-reminder>` tags, clearly separated from user input.
3. **Parallel tool-call batching** — prompt explicitly trains the model to batch independent calls in one message.
4. **Env block + git snapshot at session start** — model gets cwd/platform/date/gitStatus without tool calls.
5. **Conciseness enforcement via examples** — few-shot verbosity calibration inside the system prompt.
6. **Specialized subagent prompts** — Piebald shows Claude Code doesn't use one prompt for everything: code review runs as multi-phase agent pipelines (finder → verification → report), summarization has 4 size variants.
7. **Background shells as first-class tools** — BashOutput/KillBash pair with `run_in_background`.
